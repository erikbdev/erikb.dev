# An Interactive Portfolio Over SSH

I've been working with [swift-nio-ssh](https://github.com/apple/swift-nio-ssh) to build an interactive, terminal-based version of this portfolio that you can access straight from your terminal. It renders a full TUI experience over an SSH connection, no browser required.

Give it a try:

```bash
ssh erikb.dev
```
